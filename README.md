### API Testing — SWAPI (Postman)

Практическая работа по тестированию REST API на примере Star Wars API.

- [Postman Collection](api-testing/postman/SWAPI%20%E2%80%94%20REST%20API%20Testing.postman_collection.json) — коллекция из 9 GET-запросов с автоматизированными проверками ответов API.

**Инструменты:** Postman, JavaScript.

### API Testing — Yandex Disk (Postman)

Практический проект по тестированию REST API облачного хранилища Яндекс Диск.

- [Yandex Disk REST API Testing](https://github.com/anastasia-shershneva/qa-portfolio/blob/main/api-testing/yandex-disk-api-testing.md) — 13 запросов: получение информации о диске, создание папок, загрузка, перемещение, удаление и восстановление файлов.
- [Postman Collection](https://github.com/anastasia-shershneva/qa-portfolio/blob/main/api-testing/postman/Yandex%20Disk%20%E2%80%94%20REST%20API%20Testing.postman_collection.json) — коллекция из 13 запросов с автоматизированными проверками ответов API.

В ходе проверки подтверждено 29 успешных результатов автоматизированных проверок. Для отдельных запросов, включая запрос 07 и операции жизненного цикла файлов, предусмотрена предварительная подготовка тестовых данных.

**Инструменты:** Postman, JavaScript, Yandex Disk REST API.

### Manual Testing & Chrome DevTools — SauceDemo

Практический проект по ручному тестированию веб-приложения SauceDemo с использованием Chrome DevTools.

- [SauceDemo — Manual Testing & Chrome DevTools](devtools/chrome-devtools-manual-testing.md) — функциональное тестирование авторизации и корзины, анализ сетевых запросов, Cookies и Storage, Console, HTML/CSS, Timing и проверка поведения приложения при ограничении сети.

**Проверяемые области:**
- Позитивное и негативное тестирование.
- Валидация формы авторизации.
- Проверка пользовательских сценариев корзины.
- Анализ HTTP-запросов и статусов.
- Исследование браузерного хранилища.
- Проверка работы приложения в режимах 3G и Offline.

**Инструменты:** Google Chrome, Chrome DevTools.
