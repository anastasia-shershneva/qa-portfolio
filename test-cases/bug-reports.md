# Bug Reports — Учебные примеры

## Общая информация

**Проект:** учебное веб-приложение авторизации.

**Тип документа:** примеры оформления дефектов.

**Примечание:** все дефекты в этом документе смоделированы для учебного портфолио. Они не являются результатами тестирования реального коммерческого продукта.

---

## BUG-001 — Авторизация выполняется с неверным паролем

**Severity:** Critical  
**Priority:** High  
**Тип:** Functional  
**Окружение:** Web, Chrome

**Предусловие:**
Зарегистрирован пользователь `valid_user` с установленным паролем.

**Шаги воспроизведения:**
1. Открыть страницу авторизации.
2. Ввести логин `valid_user`.
3. Ввести неверный пароль `WrongPass123!`.
4. Нажать кнопку «Войти».

**Ожидаемый результат:**
Авторизация не выполняется. Пользователь остаётся на странице входа. Отображается сообщение об ошибке.

**Фактический результат:**
Авторизация выполняется, пользователь получает доступ к личному кабинету с неверным паролем.

**Комментарий:**
Дефект нарушает основной механизм аутентификации и может привести к несанкционированному доступу.

## BUG-002 — Кнопка «Войти» не реагирует на нажатие Enter

**Severity:** Medium  
**Priority:** Medium  
**Тип:** Functional  
**Окружение:** Web, Chrome

**Предусловие:**
Открыта страница авторизации. Есть зарегистрированный пользователь.

**Шаги воспроизведения:**
1. Ввести корректный логин.
2. Ввести корректный пароль.
3. Установить курсор в поле пароля.
4. Нажать клавишу Enter.

**Ожидаемый результат:**
Форма отправляется, выполняется авторизация пользователя.

**Фактический результат:**
Нажатие Enter не приводит к отправке формы. Для авторизации необходимо нажать кнопку мышью.

**Комментарий:**
Пользователь не может воспользоваться стандартным способом отправки формы с клавиатуры.

**Priority:** High

**Окружение:** Web, Chrome

**Шаги воспроизведения:**
1. Открыть страницу авторизации.
2. Ввести пароль в соответствующее поле.

## BUG-004 — Приложение не обрабатывает слишком длинный логин

**Severity:** Medium  
**Priority:** Medium  
**Тип:** Functional / Validation  
**Окружение:** Web, Chrome

**Предусловие:**
Открыта страница авторизации.

**Шаги воспроизведения:**
1. Ввести в поле логина строку длиной 21 символ.
2. Ввести произвольный пароль.
3. Нажать кнопку «Войти».

**Ожидаемый результат:**
Система отклоняет логин, превышающий допустимую длину 20 символов, и отображает сообщение о некорректном формате.

**Фактический результат:**
Система принимает логин длиной 21 символ и отправляет запрос авторизации.

**Комментарий:**
Не соблюдается ограничение максимальной длины логина.

## BUG-006 — Сообщение об ошибке не отображается при пустом поле логина

**Severity:** Low  
**Priority:** Medium  
**Тип:** UI / Validation  
**Окружение:** Web, Chrome

**Предусловие:**
Открыта страница авторизации.

**Шаги воспроизведения:**
1. Оставить поле логина пустым.
2. Ввести произвольный пароль.
3. Нажать кнопку «Войти».

**Ожидаемый результат:**
Под полем логина отображается сообщение «Введите логин». Поле визуально выделяется.

**Фактический результат:**
Сообщение об ошибке не отображается. Пользователь не понимает, почему авторизация не выполняется.

**Комментарий:**
Недостаточная обратная связь затрудняет использование формы.

## BUG-007 — Повторная отправка формы при многократном нажатии кнопки «Войти»

**Severity:** Medium  
**Priority:** Medium  
**Тип:** Functional  
**Окружение:** Web, Chrome

**Предусловие:**
Открыта страница авторизации. Введены корректные учётные данные.

**Шаги воспроизведения:**
1. Ввести корректный логин.
2. Ввести корректный пароль.
3. Быстро нажать кнопку «Войти» несколько раз подряд.
4. Проверить количество отправленных запросов авторизации.

**Ожидаемый результат:**
Выполняется только один запрос авторизации. Повторные нажатия не создают дублирующие запросы.

**Фактический результат:**
При каждом нажатии отправляется отдельный запрос авторизации.

**Комментарий:**
Повторная отправка может создавать лишнюю нагрузку и приводить к некорректному поведению интерфейса.

## BUG-008 — JavaScript выполняется при вводе специальной строки в поле логина

**Severity:** Critical  
**Priority:** High  
**Тип:** Security / XSS  
**Окружение:** Web, Chrome

**Предусловие:**
Открыта страница авторизации.

**Шаги воспроизведения:**
1. Открыть страницу авторизации.
2. Ввести в поле логина строку `<script>alert(1)</script>`.
3. Отправить форму.
4. Проверить, выполняется ли JavaScript-код.

**Ожидаемый результат:**
Введённая строка обрабатывается как обычный текст. JavaScript-код не выполняется. Приложение продолжает работать корректно.

**Фактический результат:**
При обработке введённой строки выполняется JavaScript-код, появляется всплывающее окно `alert(1)`.

**Комментарий:**
Возможная XSS-уязвимость. Требуется проверка обработки пользовательского ввода и безопасного вывода данных.

## Примечание

Severity отражает степень влияния дефекта на работу приложения.

Priority отражает срочность исправления дефекта.

Все описанные дефекты являются учебными сценариями. Для реального баг-репорта фактический результат должен подтверждаться воспроизведением дефекта в тестируемой системе.
