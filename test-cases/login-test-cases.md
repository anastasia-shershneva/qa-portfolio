# Login Form — Test Cases

## Test Scenario
Проверка формы авторизации пользователя.

## Test Cases

### TC-01 — Успешная авторизация
**Предусловие:** Пользователь зарегистрирован.
**Шаги:**
1. Ввести корректный логин.
2. Ввести корректный пароль.
3. Нажать кнопку «Войти».

**Ожидаемый результат:** Пользователь успешно авторизован.

### TC-02 — Неверный пароль
**Шаги:**
1. Ввести корректный логин.
2. Ввести неправильный пароль.
3. Нажать кнопку «Войти».

**Ожидаемый результат:** Отображается сообщение об ошибке авторизации.

### TC-03 — Пустой логин
**Шаги:**
1. Оставить поле логина пустым.
2. Ввести пароль.
3. Нажать кнопку «Войти».

**Ожидаемый результат:** Отображается сообщение о необходимости заполнить логин.

### TC-04 — Пустой пароль
**Шаги:**
1. Ввести логин.
2. Оставить поле пароля пустым.
3. Нажать кнопку «Войти».

**Ожидаемый результат:** Отображается сообщение о необходимости заполнить пароль.

### TC-05 — Пробелы в логине
**Шаги:**
1. Ввести логин с пробелами в начале и конце.
2. Ввести корректный пароль.
3. Нажать «Войти».

**Ожидаемый результат:** Система обрабатывает пробелы согласно требованиям к формату логина.

### TC-06 — Переключение видимости пароля
**Шаги:**
1. Ввести пароль.
2. Нажать на значок отображения пароля.

**Ожидаемый результат:** Пароль отображается открытым текстом. Повторное нажатие скрывает его.

### TC-07 — Вход клавишей Enter
**Шаги:**
1. Ввести корректный логин.
2. Ввести корректный пароль.
3. Нажать Enter.

**Ожидаемый результат:** Выполняется попытка авторизации.

### TC-08 — Повторное нажатие кнопки «Войти»
**Шаги:**
1. Ввести корректные учётные данные.
2. Несколько раз быстро нажать «Войти».

**Ожидаемый результат:** Не создаются дублирующиеся запросы авторизации.

### TC-09 — Проверка регистра логина
**Шаги:**
1. Ввести логин с изменённым регистром букв.
2. Ввести корректный пароль.
3. Нажать «Войти».

**Ожидаемый результат:** Поведение соответствует требованиям к регистру логина.

### TC-10 — Проверка защищённости пароля
**Шаги:**
1. Открыть форму авторизации.
2. Ввести пароль.
3. Проверить отображение символов в поле.

**Ожидаемый результат:** По умолчанию пароль скрыт за специальными символами.
