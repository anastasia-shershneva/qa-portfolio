# Yandex Disk REST API Testing

Практический проект по тестированию REST API облачного хранилища Яндекс Диск с использованием Postman.

## Цель проекта

Проверить основные операции API для работы с файлами и папками, а также протестировать обработку ответов сервера.

## Область тестирования

В коллекцию Postman включены 13 запросов:

- Получение информации о диске.
- Создание папки.
- Получение ссылки для загрузки файла с компьютера.
- Загрузка файла на Диск.
- Загрузка файла по URL.
- Проверка статуса операции загрузки.
- Перемещение файла.
- Проверка перемещённого файла.
- Удаление файла.
- Проверка удаления файла.
- Восстановление файла из Корзины.
- Поиск файла в Корзине.
- Проверка восстановленного файла.

## Автоматизированные проверки

Для проверки ответов API использовались JavaScript-тесты в Postman Sandbox (`pm.test`, `pm.response`, `pm.expect`).

Проверки включают:

- HTTP status codes;
- корректность JSON-ответов;
- наличие обязательных полей;
- значения имени и пути файла;
- наличие ссылки для загрузки;
- успешное завершение асинхронной операции;
- наличие элементов в ответе Корзины.

## Используемые инструменты

- Postman
- Yandex Disk REST API
- JavaScript

## Настройка

Для выполнения запросов необходим OAuth-токен Яндекс Диска.

Перед запуском коллекции:

1. Создать собственное окружение Postman.
2. Добавить переменную `oauth_token` и указать личный OAuth-токен.
3. Выбрать созданное окружение.

Токен не включён в опубликованную коллекцию.

Для запроса **04 — Upload File to Disk** необходимо самостоятельно выбрать локальный файл в настройках Body → file.

Для запроса **11 — Restore File from Trash** необходимо указать актуальный путь файла в Корзине. Его можно получить с помощью запроса **12 — Find File in Trash**.
