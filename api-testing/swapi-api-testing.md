
# SWAPI REST API Testing

## 1. О проекте

**Цель:** продемонстрировать практические навыки тестирования REST API с использованием Postman на примере Star Wars API (SWAPI).

**Инструмент:** Postman  
**Тип запросов:** HTTP GET  
**Формат ответов:** JSON, Wookiee  
**Базовый URL:** https://swapi.py4e.com/api/

## 2. Выполненные задания

В рамках практической работы изучались:
- структура REST API и доступные эндпоинты;
- получение и анализ JSON-ответов;
- работа с JSON Schema;
- query-параметры и пагинация;
- поиск ресурсов по имени;
- получение данных в альтернативном формате Wookiee.

## 3. Практические задания

### 3.1. Получение списка эндпоинтов

**Задача:** посмотреть все доступные ресурсы API.

**Метод:** GET

**URL:**
```http
https://swapi.py4e.com/api/
```

**Ожидаемый результат:** JSON-объект со ссылками на доступные ресурсы: people, planets, films, species, vehicles и starships.

### 3.2. Определение количества персонажей

**Задача:** узнать, сколько людей сохранено в базе данных SWAPI.

**Метод:** GET

**URL:**
```http
https://swapi.py4e.com/api/people/
```


**Ожидаемый результат:** JSON-ответ с полем `count`, содержащим общее количество персонажей. На момент проверки API возвращает `87`. Поле `results` содержит записи текущей страницы.

### 3.3. Получение JSON Schema для people

**Задача:** посмотреть структуру данных и типы полей ресурса people.

**Метод:** GET

**URL:**
```http
https://swapi.py4e.com/api/people/schema/
```

**Ожидаемый результат:** описание структуры ресурса people, его полей и типов данных.

### 3.4. Определение параметра перехода на следующую страницу

**Задача:** определить query-параметр, который используется для перехода между страницами результатов.

**Метод:** GET

**URL:**
```http
https://swapi.py4e.com/api/people/?page=2
```

**Ожидаемый результат:** получение следующей страницы списка персонажей.

**Параметр:** `page`.

### 3.5. Изучение описания ресурса starships

**Задача:** определить, что означает ресурс `starships` в корневом объекте API.

**Метод:** GET

**URL:**
```http
https://swapi.py4e.com/api/
```

**Ответ:** `starships` — это ссылка на эндпоинт ресурса космических кораблей (Starships). Через неё можно получить список доступных космических кораблей.

### 3.6. Получение информации о персонаже Han Solo

**Задача:** найти персонажа Han Solo и определить его ID.

**Метод:** GET

**URL:**
```http
https://swapi.py4e.com/api/people/14/
```

**Ожидаемый результат:** JSON-объект с информацией о персонаже Han Solo.

**ID персонажа:** `14`.

### 3.7. Получение информации о Han Solo на языке Wookiee

**Задача:** получить данные о Han Solo в альтернативном формате Wookiee.

**Метод:** GET

**URL:**
```http
https://swapi.py4e.com/api/people/14/?format=wookiee
```

**Ожидаемый результат:** ответ API с данными персонажа в формате Wookiee.

### 3.8. Определение названия поля URL на языке Wookiee

**Задача:** определить, как называется поле `url` в ответе API на языке Wookiee.

**Метод:** GET

**URL:**
```http
https://swapi.py4e.com/api/people/14/?format=wookiee
```

**Результат:** поле `url` в формате Wookiee обозначается как `hurcan`.

### 3.9. Поиск персонажа Obi-Wan Kenobi

**Задача:** найти персонажа Obi-Wan Kenobi среди всех записей ресурса people.

**Метод:** GET

**URL:**
```http
https://swapi.py4e.com/api/people/?search=Obi-Wan%20Kenobi
```

**Query-параметр:** `search`.

**Ожидаемый результат:** JSON-ответ с найденным персонажем Obi-Wan Kenobi и его данными.
