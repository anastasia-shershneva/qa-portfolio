# SWAPI — REST API Testing

## Описание проекта

Практический проект по тестированию REST API на примере Star Wars API (SWAPI).

**Цель проекта:** изучить структуру REST API, научиться отправлять GET-запросы, анализировать JSON-ответы и проверять корректность получаемых данных с помощью Postman.

## Выполненные задания

В рамках практической работы выполнено 9 заданий:

1. Изучена структура API и получен список доступных эндпоинтов.
2. Определено количество персонажей в базе данных API.
3. Изучен JSON Schema эндпоинта `people`.
4. Проверен параметр пагинации для получения следующей страницы результатов.
5. Изучена информация об эндпоинте `starships`.
6. Найден идентификатор персонажа Han Solo.
7. Получен ответ о Han Solo в формате Wookiee.
8. Проверено название поля URL в Wookiee-ответе.
9. Выполнен поиск персонажа Obi-Wan Kenobi среди людей.

## Автоматизированные проверки в Postman

Для проверки ответов API использовались тестовые скрипты на JavaScript с применением Postman Sandbox API (`pm.test`, `pm.response`, `pm.expect`).

Автоматизированные проверки включали:

- HTTP status codes;
- корректность формата JSON;
- наличие обязательных полей;
- проверку значений отдельных полей;
- количество элементов в ответе;
- корректность поисковой выдачи;
- соответствие URL ожидаемому ресурсу.

Все 9 запросов коллекции имеют автоматизированные проверки.
