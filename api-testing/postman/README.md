# Postman Collections

Здесь хранятся коллекции Postman с запросами и автоматизированными проверками API.

## SWAPI — REST API Testing

- 9 GET-запросов к SWAPI.
- Проверка HTTP-статусов.
- Проверка JSON-ответов и структуры данных.
- Проверка пагинации.
- Поиск персонажей.
- Проверка Wookiee-формата.

**Формат коллекции:** Postman Collection v2.1.
