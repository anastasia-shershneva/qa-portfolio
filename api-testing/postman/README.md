# Postman Collections — API Testing

В этом разделе представлены коллекции Postman для практического тестирования REST API.

## Проекты

### 1. SWAPI — REST API Testing

Тестирование Star Wars API.

- 9 GET-запросов.
- Проверка структуры API, JSON Schema и пагинации.
- Поиск персонажей.
- Работа с форматом Wookiee.
- Автоматизированные проверки ответов API на JavaScript.

[Открыть коллекцию SWAPI](SWAPI%20%E2%80%94%20REST%20API%20Testing.postman_collection.json)

[Описание проекта SWAPI](../swapi-api-testing.md)

### 2. Yandex Disk — REST API Testing

Тестирование REST API облачного хранилища Яндекс Диск.

- 13 запросов для работы с файлами и папками.
- Получение информации о диске.
- Создание папок, загрузка, перемещение и удаление файлов.
- Восстановление файлов из корзины.
- Автоматизированные проверки ответов API на JavaScript.

[Открыть коллекцию Yandex Disk](Yandex%20Disk%20%E2%80%94%20REST%20API%20Testing.postman_collection.json)

[Описание проекта Yandex Disk](../yandex-disk-api-testing.md)

## Инструменты

- Postman
- JavaScript (Postman Sandbox)
- REST API
