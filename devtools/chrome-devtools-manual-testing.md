# Chrome DevTools — Manual Testing

## 1. О проекте

Практический проект по использованию Chrome DevTools в ручном тестировании веб-приложений.

В рамках проекта выполнены проверки сетевых запросов, HTTP-ответов, заголовков и кэширования с использованием вкладки Network.

## 2. Объект тестирования

- Приложение: [SauceDemo](https://www.saucedemo.com/)
- Инструмент: Chrome DevTools
- Браузер: Google Chrome
- Тип тестирования: ручное тестирование (Manual Testing)

## 3. Проверки Network

### 3.1. Проверка основного HTTP-запроса

- Тип запроса: `document`
- Request Method: `GET`
- URL: HTTPS
- HTTP Status Code: `200 OK`

### 3.2. Проверка кэширования

При первоначальной загрузке страницы получен статус:

- `304 Not Modified`

В заголовках ответа обнаружено:

- `max-age=600`

После включения настройки `Disable cache` и повторной загрузки страницы получен статус:

- `200 OK`

**Вывод:** проверено поведение браузера при использовании кэшированной версии ресурса и при отключённом кэшировании.

### 3.3. Анализ ответа сервера

Вкладка Response содержит HTML-код документа.

Вкладка Preview отображает сообщение:

`You need to enable JavaScript to run this app`

**Вывод:** HTML-документ загружается, а для отображения интерфейса приложения требуется JavaScript.
