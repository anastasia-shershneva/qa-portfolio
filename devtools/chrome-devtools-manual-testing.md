
# Ручное тестирование SauceDemo с использованием Chrome DevTools

## 1. О проекте

В рамках проекта проведено ручное тестирование веб-приложения [SauceDemo](https://www.saucedemo.com/) и исследованы возможности Chrome DevTools.

**Цель:** проверить основные пользовательские сценарии приложения и изучить сетевое взаимодействие, браузерное хранилище, консоль и поведение приложения при различных условиях сети.

### Область тестирования

- Функциональное тестирование авторизации.
- Проверка валидации полей.
- Проверка добавления и удаления товара из корзины.
- Анализ сетевых запросов и HTTP-статусов.
- Проверка Cookies, Local Storage и Session Storage.
- Анализ Console.
- Проверка HTML и CSS через Elements.
- Анализ времени ответа сервера.
- Проверка Network Throttling: 3G и Offline.

### Окружение

| Параметр | Значение |

| Браузер | Google Chrome |

### 2.3. Оформление заказа

**Цель:** проверить путь от добавления товара в корзину до подтверждения заказа, включая валидацию обязательных полей.

**Окружение:** веб-версия SauceDemo, настольный браузер, 11.11.2026.  
**Тестовые данные:** пользователь `standard_user`, товар `Sauce Labs Backpack`, имя `Test`, фамилия `Buyer`, почтовый индекс `12345`.

| № | Действие | Ожидаемый результат | Фактический результат | Статус |
|---|---|---|---|---|
| 1 | Добавить рюкзак и открыть корзину | Счётчик показывает 1, в корзине выбранный товар | В корзине Sauce Labs Backpack за $29.99, счётчик показывает 1 | Pass |
| 2 | Нажать Continue, оставив все поля пустыми | Форма остаётся открытой и сообщает, что имя обязательно | `Error: First Name is required` | Pass |
| 3 | Заполнить только First Name и нажать Continue | Форма сообщает, что фамилия обязательна | `Error: Last Name is required` | Pass |
| 4 | Заполнить First Name и Last Name, оставить индекс пустым и нажать Continue | Форма сообщает, что индекс обязателен | `Error: Postal Code is required` | Pass |
| 5 | Ввести индекс `12345` и нажать Continue | Открывается Checkout: Overview с выбранным товаром | Открылся Checkout: Overview, в списке Sauce Labs Backpack | Pass |
| 6 | Сверить стоимость товара, налог и итоговую сумму | Цена совпадает с корзиной, итог равен стоимости товара плюс налог | $29.99 + $2.40 = $32.39 | Pass |
| 7 | Нажать Finish | Появляется подтверждение заказа, корзина очищается | `Thank you for your order!`, корзина пуста | Pass |
| 8 | Нажать Back Home | Открывается каталог, корзина остаётся пустой | Открылась страница Products, корзина пуста | Pass |

**Итог:** 8 из 8 проверок прошли. В рамках этого прогона расхождений не обнаружено.

**Дополнительная проверка в Safari на iPhone — пройдена.** При попытке продолжить оформление с пустым полем `Zip/Postal Code` появилось сообщение `Error: Postal Code is required`. Сообщение осталось видимым после открытия клавиатуры. После ввода `350000` и повторного нажатия `Continue` открылась страница `Checkout: Overview`.

## 3. Chrome DevTools

### 3.1. Network — сетевые запросы

| Проверка | Результат |
|---|---|

| JavaScript | 1 запрос, HTTP 200 |
| CSS | 2 запроса, HTTP 200 |
| Изображения на странице авторизации | Не обнаружены в проверенном фильтре |
| Fetch/XHR до авторизации | Запросы не обнаружены |
| Fetch/XHR после авторизации | Отдельные запросы не обнаружены в зафиксированном представлении |
| Запросы в фильтре All после авторизации | Отображавшиеся запросы имели статус 200 |

В URL основного документа присутствовал параметр `utm_source=chatgpt.com`.

Заголовок `Content-Type` не был виден в просмотренной вкладке Response Headers. Это наблюдение интерфейса DevTools, а не подтверждение отсутствия заголовка на стороне сервера.

### 3.2. Application — Cookies и Storage

Проверены Cookies, Local Storage и Session Storage домена `https://www.saucedemo.com`.

**Local Storage:**

- `backtrace-guid`
- `backtrace-last-active`

Среди просмотренных записей ключи с именем пользователя или данными авторизации не обнаружены.

**Session Storage:**

Записи отсутствовали.

**Cookies:**

После успешной авторизации обнаружена cookie `session-username`.

| Атрибут | Значение |
|---|---|
| Name | `session-username` |
| Domain | `www.saucedemo.com` |
| Path | `/` |
| HttpOnly | No |
| Secure | No |
| SameSite | Не отображался |

Значение cookie в документации не приводится.

**Наблюдение:** у обнаруженной cookie не был установлен атрибут HttpOnly, поэтому она доступна JavaScript. Атрибут Secure также не был установлен в просмотренных свойствах. Это техническое наблюдение, а не подтверждённая уязвимость.

### 3.6. Network Throttling — ограничение сети

**Профиль 3G**

После выбора профиля 3G и перезагрузки страницы товаров отобразилась форма авторизации с сообщением:

```text
Epic sadface: You can only access '/inventory.html' when you are logged in.
```

После восстановления обычного сетевого режима и повторной перезагрузки страница товаров открылась без повторного ввода учётных данных.

Причина поведения не установлена. Результат зафиксирован как наблюдение, а не подтверждённый дефект.

**Профиль Offline**

После выбора Offline и перезагрузки страницы товаров основной запрос документа завершился ошибкой:

```text
net::ERR_INTERNET_DISCONNECTED
```

В Network запрос `inventory.html` отображался со статусом `(failed)`, временем выполнения около 4 мс и объёмом передачи 0,0 kB.

Отдельные изображения внутренней страницы ошибки Chrome были загружены из memory cache и не рассматривались как ресурсы приложения.

После восстановления режима No throttling и повторной перезагрузки страница товаров открылась.

## 5. Основные наблюдения

1. Форма авторизации корректно обработала проверенные сценарии с неверными и отсутствующими учётными данными.
2. Проверенные действия с корзиной работали ожидаемым образом.
3. Основной документ и просмотренные ресурсы при обычном подключении возвращали HTTP 200.
4. В Console обнаружено сообщение о нарушении Permissions Policy, связанное с `unload`.
5. Обнаружена cookie `session-username` без атрибутов HttpOnly и Secure.
6. Поведение страницы при профиле 3G требует дополнительного исследования.
7. При отсутствии подключения загрузка основного документа завершилась сетевой ошибкой.
